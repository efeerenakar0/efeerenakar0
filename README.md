## How I work

1. Start with the outcome and reduce the problem to a clear user journey.
2. Build the smallest coherent system that can grow without unnecessary complexity.
3. Validate behavior, responsiveness, accessibility, and failure states before delivery.
4. Keep implementation and presentation aligned—quality should be visible and maintainable.
